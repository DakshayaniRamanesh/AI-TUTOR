## 1. Executive Summary

**AI-TUTOR (Kestrel)** bridges the gap between passive note-taking and active visual learning. Instead of reading flat PDFs or static formulas, students can:
1. **Draw & Write Freely**: Work on an infinite vector canvas with pen input, sticky notes, formulas, and cards.
2. **Generate Mathematical Animations (Manim)**: Turn complex concepts, equations, or PDF excerpts into custom high-definition MP4 animations generated by an AI agent pipeline.
3. **Solve & Visualize Equations**: Instantly solve calculus/algebra queries with SymPy and render beautiful mathematical function plots directly onto the canvas.
4. **Annotate Videos**: Pause generated animations and draw over specific frames to submit visual notes back to the AI.
5. **Explore Knowledge Networks**: Automatically visualize connections between topics using a dynamic force-directed knowledge graph based on markdown tags and links.

## 3. Core Concepts

### 💡 1. The Canvas as a Unified Learning Hub
Instead of separate windows for reading, writing, and watching videos, Kestrel treats the **Canvas** as a spatial workspace. Videos, PDF clips, math plots, handwritten ink, and markdown cards live together on a single zoomable surface.

### 💡 2. Agentic Animation Generation
Instead of relying on rigid video templates, Kestrel uses **LangGraph** to coordinate specialized AI LLM agents (Story Agent, CodeGen Agent, Validator) that write raw Python code using **Manim** (3Blue1Brown's animation engine) and compile it into custom video tutorials.

### 💡 3. Self-Healing Code Harness
When LLMs write complex animation code, compilation errors can occur. Kestrel features an automated **CI Harness node** that runs the code in a sandbox. If an error trace is returned, the CodeGen agent receives the exact error and line number to debug and rewrite the code automatically.

### 💡 4. Cross-Student Semantic Caching
Mathematical concepts are universal. If Student A requests a video explaining *Fourier Transforms* from a specific physics PDF chapter, Kestrel hashes the context and prompt into Qdrant. When Student B requests a similar explanation later, Qdrant returns the pre-rendered HD video instantly without spending cloud GPU compute.

## 4. Detailed Feature Breakdown

### 4.1 Infinite Freeform Canvas & Interactive Items
- **Vector Pen & Ink (`InkStrokeItem`)**: Smooth freehand drawing with configurable stroke width, colors, pressure sensitivity, and eraser tool.
- **Handwriting Note & OCR (`HandwritingNoteItem`, `handwriting_ocr.py`)**: Converts hand-drawn strokes into digital text via optical character recognition.
- **Floating Video Player (`VideoFloatItem`)**: Embedded player with play/pause, scrub bar, zoom, and overlay mode to play generated Manim videos directly on the canvas.
- **Sticky Notes (`StickyNoteItem`)**: Color-coded quick reference notes with formatted text.
- **Markdown & Study Cards (`CardItem`)**: Structured note cards supporting rich text, bullet points, and code formatting.
- **Dynamic Function Plots (`GraphCardItem`)**: Visual math plots rendered by Matplotlib and SymPy.
- **AI Answer Bubbles (`AnswerBubbleItem`)**: Speech-bubble style cards anchored to specific coordinates containing AI responses.
- **Spatial Map Pins (`MapPinCard`)**: Waypoints and bookmarks on the infinite canvas for easy navigation.
- **Item Grouping (`GroupSelectionGroup`)**: Multi-select, align, rotate, and move canvas elements together.

---

### 4.2 Agentic Manim Video Generation Pipeline
Located in `backend/pipeline/graph.py`, the video generator uses **LangGraph** to execute a state machine:

1. **Document Embedder Node (`embed`)**:
   - Parses uploaded PDF documents.
   - Extracts text, splits into semantic chunks, and generates vector embeddings via `models/text-embedding-004` into Qdrant.
2. **Story Agent Node (`story`)**:
   - Analyzes user prompts alongside retrieved PDF context chunks.
   - Writes a step-by-step visual storyboard detailing scene transitions, text overlays, and mathematical animations.
3. **Validator Node (`validate`)**:
   - Inspects the storyboard for clarity, pedagogical correctness, and structural integrity.
   - If flawed, loops back to `story` with actionable feedback.
4. **CodeGen Agent Node (`codegen`)**:
   - Converts the validated storyboard into clean, runnable Python code targeting the **Manim** animation library (`manim.mobject`, `manim.animation`).
5. **CI Harness Node (`ci`)**:
   - Sandboxed execution node. Executes `manim -qp script.py` to compile the scene.
   - **Self-Healing Loop**: If rendering fails, catches `stdout`/`stderr` stack trace, packages it into a prompt, and routes back to `codegen` for auto-repair (up to 3 retry attempts).
6. **Renderer Agent Node (`render`)**:
   - On CI approval, renders full resolution MP4 animations on GPU compute (Modal A10G serverless cloud or local machine).
7. **Uploader Node (`upload`)**:
   - Uploads final MP4 artifacts to cloud storage / local storage and returns video URLs.

---

### 4.3 Cross-Student Semantic Video Cache (Qdrant)
Located in `backend/rag/qdrant_store.py`:
- **Dual Collections**:
  - `manim-docs-v4`: Stores document text chunks and vector embeddings.
  - `manim-video-cache-v3`: Stores prompt-PDF fingerprint pairs and rendered video output URLs.
- **Matching Algorithm**:
  - **Exact Hash Match**: Hashes prompt + first 2,000 chars of PDF context.
  - **Semantic Vector Match**: If exact hash misses, performs vector similarity search in Qdrant. If cosine similarity > `0.92`, returns the cached video URL immediately.

---

### 4.4 STEM Symbolic Solver & Dynamic Plotter
Located in `app/backend/stem_solver.py`:
- **SymPy Integration**: Solves symbolic mathematics locally:
  - Differentiation (`d/dx`)
  - Definite & Indefinite Integration (`integral(...)`)
  - Limits (`lim x->a`)
  - Algebraic Equation Solving (`solve(...)`)
  - Matrix operations and simplification
- **Automatic Graphing**:
  - Detects if an equation represents a plottable 2D function.
  - Generates custom styled plots using `matplotlib`.
  - Saves PNG assets and inserts them as interactive `GraphCardItem` elements on the canvas.

---

### 4.5 Interactive Video Ink Annotations
Located in `backend/pipeline/annotation_handler.py`:
- Users can pause a playing Manim video on the canvas.
- Draw directly on top of video frames to point out details or add custom diagrams.
- Clicking **"Stitch Annotations"** sends stroke coordinates, timestamps, and colors to the backend.
- The backend overlays ink vector paths onto the exact video frames using FFmpeg / OpenCV and outputs a updated MP4 video.

---

### 4.6 Knowledge Graph & Obsidian Tag Parser
Located in `app/ui/views/obsidian_graph_panel.py` and `app/backend/tag_graph_parser.py`:
- Scans all notebook cards, sticky notes, and documents for markdown tags (`#algebra`, `#physics`, `#calculus`) and internal wiki-links (`[[Derivative Rules]]`).
- Constructs a graph network where nodes represent topics/notes and edges represent relationships.
- Renders an interactive force-directed graph (using PyQt / PyGraphviz / WebEngine) to let students visually explore connections across their study notes.

---

### 4.7 PDF Grounded RAG & Study Mode
Located in `app/backend/pdf_rag_manager.py` & `app/ui/widgets/reference_panel.py`:
- Built-in PDF reader supporting text extraction, search, and page thumbnail navigation.
- **Study Mode**: Select text or ask questions in the reference panel.
- Performs retrieval augmented generation (RAG) over indexed course materials, displaying answers alongside page number citations and source quotes.

---

### 4.8 Git Notes Version Control System (VCS)
Located in `app/backend/git_notes_manager.py` & `app/ui/views/git_notes_panel.py`:
- Built-in Git versioning tailored for student notes.
- Automatically creates commits/snapshots when notebooks are modified.
- Allows students to browse history, compare revisions, restore old versions of notes, and manage branching without losing work.

---

### 4.9 Native LaTeX Rendering Engine
Located in `app/backend/latex_client.py` & `app/backend/latex_formatter.py`:
- Uses local `Tectonic` TeX engine or native SymPy rendering to compile math expressions (`\int_{0}^{\infty} e^{-x^2} dx = \frac{\sqrt{\pi}}{2}`) into sharp vector PNG/SVG graphics.
- Renders math formulas dynamically on canvas cards, sticky notes, and video titles.

## 5. End-to-End Workflows & Data Flows

### Workflow A: Prompt / PDF to Manim Video

```
[User Canvas] 
     |
     v  (Types prompt & selects PDF area)
[video_gen_client.py]
     |
     +---> [FastAPI Server (local_server.py) or Modal Cloud (modal_app.py)]
                  |
                  v
         [Qdrant Cache Check]
         /                  \
   (Cache Hit >0.92)      (Cache Miss)
       /                      \
[Return Cached MP4]       [LangGraph Pipeline]
                               |--> Embed PDF -> Story Agent -> Validator
                               |--> CodeGen Agent -> CI Test Sandbox
                               |         ^                     |
                               |         +--(If Error: Retry)--+ (Max 3)
                               v
                       [Manim GPU Render] ---> [Save to Qdrant Cache]
                               |
                               v
                       [Play MP4 on Canvas VideoFloatItem]
```

### Workflow B: Math Equation to Visual Canvas Plot

```
[User Ask Bar] (e.g., "plot d/dx (x^3 - 3x)")
     |
     v
[stem_solver.py]
     |
     +---> [SymPy Parsing & Symbolic Differentiation]
     |        |-> Result: 3*x^2 - 3
     |
     +---> [Matplotlib Generator]
              |-> Generates curve plot PNG
     |
     v
[Canvas Scene] ---> Displays formatted LaTeX AnswerBubble + GraphCardItem
```
